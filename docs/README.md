### 最終盤の判断と、その結果の正直な評価

締切24.6h前に両枠を champion で再投入した。根拠は「このラダーは提出を約24hでピークにし
以降減衰させる」という観測で、当時の両枠は83h経過して減衰相にあった。

**この賭けは外れた。** champion の過去6回の ~24h ドローは
936.7 / 980.4 / 976.0 / 945.0 / 917.8 / 912.5（平均 944.7・sd 26.6）だったが、
最終ペアは **846.1 / 817.3** で着地した。平均から **3.7σ 下**である。

フィールド側のデフレでは説明できない。08-15→08-17 でフィールドは実質不変だった
（50位 −1.1 / 100位 −2.0 / 200位 +9.6 / 341位 +7.6 / 683位 +8.5）。
つまり**単純にドローが悪かった**か、**同一tarの分散を n=6 で見積もったのが過小だった**かのどちらかで、
記録上は後者を疑うべき根拠がある（両枠とも低く出ており、枠は独立ではない）。

**この失敗自体が Strategy レポートの素材になる。** 詳細は [FINDINGS.md](FINDINGS.md) の
「測定の失敗史」を参照。
