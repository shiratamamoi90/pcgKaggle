# 測定器の失敗史と8つの一般則
### 50提出・48施策を対照群つきで測り切った記録

**結果**: **846.1 / 673位・6,892チーム中**（上位9.8%）、提出50本・施策48件。
2026-08-17 11:23 UTC 時点の暫定値。48件の内訳は**有意に改善 0件、有意に悪化 2件**、
null 10件以上、**測定器の欠陥として発見 8件**、撤回した自分の結論 10件以上。
**この分布そのものが結論である。**

**手法**: 小型 Transformer（AlphaZero 系 2ヘッド、12.53M の98%が埋め込み、本体0.265M）。
学習は**行動クローニング1本**で、教師はラダー1位の 4,755サイド / 428,461サンプル。
**推論は貪欲で探索を切っている。** 強化学習は4形態・10回以上すべて null だった。
**「自分より強いものからしか学べない」**を先に測り、満たす手段だけを残した結果である。

**デッキ**: フーディンex ＋ ノココッチ。**構築はしていない。**
模倣を主戦略に据えた以上デッキは従属変数で、1枚動かせば教師データの外の局面が生じる。
60枚は22種、**4枚採用が9種（60%）**＝初期状態に依存せず同じ勝ち筋を反復する構成。
実ラダー 61,994サイドの構成はオーロンゲ **58.4%** / その他29.2% / フーディン9.4%。
**フーディンを使う20チーム全員がオーロンゲに負け越し**（教師本人でも49.2%）、
フィールド加重で **10種中9位（45.4%）**。**完璧に模倣しても上限は49.2%。**
オーロンゲの78.7%は175チームが共有する単一リストで、**構築は事実上終わっていた。**

**効いたのは3つだけ**。教師の質（実体はデータ量、約5,000サイドで飽和）、
貪欲推論（**+27.3pp・14/14の相手・z=9.14**）、同一basin内の重み平均。
RL 4形態・アンサンブル・容量増・デッキ移植など10軸以上が null か有害だった。

**考察。** RL の10回の null は、方策ターゲット（MCTS budget10、64.1%）が
**生徒（貪欲、85.7%）より21.6pp弱かった**ことに還元された。
**改善作用素は現方策より強くなければならない。** BCが効いたのは教師が強かったから、
MCTSが有害だったのは、隠れ情報を推測したロールアウトが
**現実には起こらない盤面の価値**を返すからである。価値損失を−56%改善しても
64.0%が38.0%に落ち（z≈−5.4）、**14体すべてで同符号＝特定マッチアップに依存しない。**

忠実度は**全指標で改善して強さは0変化**した（一致率+2.8pp、ミラー48.0%と52.5%）。
同デッキの別チームにも70.2%一致する＝**判断の7割は実質強制**で、平均指標は勝敗区間を重み付けしない。

評価相手は**デッキが58/60一致していたため古さが見えず**、実測43.6%を86.0%と報告していた
（**42.4pp**）。**カードリストは静的だが方策は動的である。**
気づけたのは**シミュレータを使わない外部基準**（リプレイ30,997試合のアーキタイプ行列、
全ミラーが50.0%で自己検証可能）を持っていたからだ。

**同一バイトの tar を繰り返し提出すると sd≈27** で散る。差分は sd≈38 なので
**単発ペアの検出下限は約76 Elo**であり、過去のラダーA/Bは全てこの下限の内側だった。
較正という手続き自体が成立しない。

デッキ移植は2回とも大敗した（**−259.4 / −186.1 Elo**）。2回目は
**アーキタイプ実勝率を0.7pp差で再現**し全オフライン指標で上回っていた。
**より良く見えるほうが、より大きく負けた。**
移植先は**試合の58.4%が同型戦**になり、同型戦は方策の質の差がそのまま出る（未検定の仮説）。
デッキ選択の効果量は19.1ppで、**最も効果量の大きい変数だけが測れなかった。**

KO可能な36回中29回（80%）の見送りは**バグではなく判断**だった。
強制すると**−13.4pp（z=−3.33）**で、害は判断を上書きした部分に集中していた。
**攻撃がターンを終える**ため、見送りが正しい局面が実在する。

**まとめ。** 改善作用素は現方策より強いこと。不完全情報下の探索は劣化要因になりうること。
忠実度は強さの代理でないこと。相手の鮮度はデッキ一致で測れないこと。
Eloラダーに検出下限があること。オフライン評価はデッキ乗り換えを予測できないこと。
明白なミスが正しい判断でありうること。メタは単一リストに収束していたこと。
相手の製造日を見る。シミュレータを使わない外部基準を持つ。判定基準を事前登録する。
「明らかなバグ」を直す前に対照群を置く。撤回した結論を記録から消さない。
**進歩を律速したのはアルゴリズムでも計算資源でもなく、
自分の測定器が嘘をついていると気づけないことだった。
そして測定器の嘘は、必ず「良い結果」の形をして現れる。**
