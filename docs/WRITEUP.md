# 測定器の失敗史と8つの一般則
### 50提出・48施策を対照群つきで測り切った記録 — ポケカ AI Battle Challenge

参加者 **shiratama**（`dotshiratama`・個人参加）/ Simulation カテゴリ 2026-06-20 から 08-16

この2ヶ月、「強くなった」と記録した結論は、数日後に
**自分の測定器の欠陥として崩れ**続けた。8回起きた。
最大のものはシミュレータが実ラダーと **42.4pp** ずれていた件で、
気づくまでの数週間、**存在しない差を見て候補を選抜していた**。

---

## 1. 結果

スコア **846.1**、**673位 / 6,892チーム（上位 9.8%）**、提出50本・施策48件。
**2026-08-17 11:23 UTC 時点の暫定値である。**
締切後もラダーは対戦を続けており、確認中に 841.6、835.5 と動いた。

48件の内訳は、**有意に改善したもの 0件**、**有意に悪化したもの 2件**、null 10件以上、
**測定器の欠陥として発見したもの 8件**、撤回した自分の結論 10件以上。
**この分布そのものが結論**であり、本レポートは
**何が効かないかを対照群つきで50提出ぶん測り切った記録**である。

## 2. 手法と最終成果物

提出物は `main.py` / `model.pth` / `deck.csv` / 公式エンジンの4点。

**方策は小型 Transformer（AlphaZero 系 2ヘッド）。** エンコーダが盤面を読んで value、
デコーダが候補手を読んで policy を出す。`d_model=128, heads=2, ff=256, enc=1, dec=1` で、
総パラメータ 12.53M のうち **98% が埋め込み**、本体は 0.265M。
カードは (index, value) の疎な組にして `EmbeddingBag` で加算するので集合情報が順序非依存になり、
与える打点のような自明な量は NN に再発見させずデコーダへ直接渡す。

**学習は行動クローニング（BC）1本。** 教師はラダー1位チームのリプレイ
4,755サイド / 428,461サンプル、12エポック。強化学習は4形態・10回以上試して全て null だった。
**推論は貪欲で、探索は切っている**（5.1節）。
以下の分析は全て、実ラダーのリプレイ7日分 **145GB** の実測から出ている。

ルールベースは ~450〜570 で頭打ち、自己BCと自己対戦RLは 46% で停滞した。
**教師を「自分」から「強い他人」に替えた瞬間に ~832 になった。**
1位チームをその正デッキ上で模倣して **934**、教師データ 3.09倍で **938.8**。
**以降11回の改良試行は1件も転移しなかった。**

## 3. デッキ

**Alakazam ex + Dudunsparce（フーディンex ＋ ノココッチ）。
構築は行っていない。教師の60枚をそのまま使った。これは意図的な選択である。**

戦略を「上位プレイヤーの方策の模倣」に置いた以上、デッキはその従属変数になる。
1枚でも動かせば教師データの外の局面が生じ、模倣の前提が崩れる。
**デッキと方策の整合を、新規性より優先した。**
支配的アーキタイプへ乗り換えるクローンを2回作り、
**2回とも大敗した**（−259.4 と −186.1 Elo、5.5節）。

60枚は **22種**、**うち9種が4枚採用（36枚 ＝ 60%）**。
初期状態に依存せず同じ勝ち筋を反復する構成で、これは方策側の要求と一致する。
**BC は分岐の多い構築より、安定した1本の勝ち筋のほうが写しやすい。**

実ラダー 61,994サイドの構成は、オーロンゲ（Marnie's Grimmsnarl ex）**58.4%**、
その他 29.2%（97種に断片化）、フーディン（私）9.4%。
**フーディンを使う20チーム全員がオーロンゲに負け越しており**（最高 49.7%、教師本人でも 49.2%）、
フィールド加重では **10種中9位の 45.4%**、首位のオーガポンは 64.5% である。
**完璧に模倣できても上限は 49.2% だった。
このデッキは強かったから選ばれたのではなく、教師が使っていたから選ばれた。**
そして**オーロンゲの 78.7% は175チームが共有する単一のリスト**だった。
**この環境ではデッキ構築が事実上終わっており、差は方策側にしか残っていなかった。**

## 4. 効いたこと・失敗したこと

効いたのは3つ。**教師の質**は 46% の壁を破ったが、これは後に**データ量**だと分かった
（同量なら純度差は 0.3pp、約5,000サイドで飽和）。**貪欲推論**は
**+27.3pp・14/14の相手で勝ち・z=9.14**。**重み平均**は同一 basin 内なら無料で伸びる一方、
独立に学習したモデル同士は **0.0%** で完全崩壊する。
効かなかった軸は10以上あり、RL 4形態、教師プール化、BC容量増、勝ち局限定BC、
リーサル強制取得、デッキ移植、ロジット・アンサンブルが含まれる。

**最も高くついた失敗は、測定器そのものの欠陥だった。**

| 欠陥 | 被害 |
|---|---|
| 相手の方策が1ヶ月古い | 実ラダー **43.6%** を 86.0% と報告 |
| 相手の自滅を自分の敗北と集計 | 同一条件で 81 / 86 / **15** / 87 / 81 / 81% |
| 沈黙する初期化バグ | **ランダム重みで推論**。26.6% が実は 61.9% |
| 蒸留ターゲットが生徒より弱い | RL 10回連続 null の唯一の原因 |
| ラダー自体の検出下限 | 同一バイトの tar が sd≈27 で散る |

## 5. 考察

### 5.1 改善作用素の条件

RL の10回の null には1つの原因があり、それはハイパラでも報酬設計でもなかった。
方策ターゲットが budget 10 の MCTS 訪問分布だった。

| 探索予算 | 勝率 | 用途 |
|---|---|---|
| **1** | **85.7%** | **出荷物すべて** |
| 10 | 64.1% | **RL 訓練ターゲット** |
| 30 | 58.4% | ローカル既定 |

**ターゲットが生徒より 21.6pp 弱かった。**

> **改善作用素は現在の方策より強くなければならない。自分より弱いものからは蒸留できない。**

この1文が3つの結果を説明する。**BC が効いた**のは教師が強かったからで、
**RL が null だった**のはターゲットが弱かったから、そして**MCTS が有害だった**のは、
相手のデッキ・手札・サイドを推測したロールアウトが
**現実には起こらない盤面の上の価値**を返すからである。
**方策が十分良くなると、探索が持ち込むバイアスが、除去する誤差を上回る。**

一度これを価値ヘッドのせいだと考え、価値損失を **−56%** 改善した網で再検定した。
結果は 64.0% が 38.0% に落ち（z≈−5.4）、**価値ヘッドは律速ではなかった。**
そしてこの結論は **14体の相手すべてで同符号（z=9.14）**であり、
**特定のマッチアップに依存した観測ではない。**
AlphaZero 系は探索が方策を改善することを前提にするが、**それは測るべき仮定であって与件ではない。**

### 5.2 忠実度は強さの代理にならない

BC の天井が模倣精度で決まると仮定し、容量とエポックを分離して測った。
訓練 CE −29%、価値損失 −56%、教師一致率 +2.8pp（z≈4.3）と
**忠実度は全指標で改善し、ミラー勝率は 48.0% と 52.5% ＝ 動かなかった。
全指標で最良の腕が実戦では最下位だった。**

対照が機構を示した。**一致率にはデッキで決まる下駄がある。**
チャンピオンは自分の教師に 78.5%、**同じデッキの別チームにも 70.2%** 一致する。
教師固有の上乗せは **+8.3pp しかない**。**判断の約7割は実質的に強制される手**なので、
勝敗を決める区間は残りの一部でしかなく、平均指標はそこをほとんど重み付けしない。
**教師（1252.8）とクローン（~914）の 325 Elo 差は、模倣誤差でも探索の欠如でも説明されない。**
共変量シフトが疑わしいが、検定には教師へのオンライン問い合わせが要る。解けなかった。

### 5.3 オフライン測定器には半減期がある

評価相手は **07-06 製**で、**デッキが現行メタと 58/60 一致していたため古さが見えなかった。**
実測 43.6%（n=3,408）に対し、シミュレータは同じ組合せを **86.0%** と報告した。
**勝ち越していると思っていた相手に、実は負け越していた。**
これで「チャンピオンは天井」という判断も、外部エージェントに依存する結論も全て無効になった。
機構は単純で、**カードリストは静的だが、方策は静的ではない。**

> **評価相手は「デッキが合っているか」ではなく「方策がいつのものか」で見る。
> 測定器の半減期を決めるのは、メタの適応速度である。**

気づけたのは**シミュレータを使わない基準**を持っていたからで、
リプレイからアーキタイプ間の勝率を集計した（30,997試合）。
自チームは n=6 だが、**アーキタイプ同士なら自チームは不要**で数万試合が使え、
全ミラーがちょうど 50.0% になることで妥当性が自己検証できる。

> **測定器の妥当性は、その内部からは検証できない。外部基準を1つ持つ。**

作り直した相手は実ラダーを **0.7pp 差**で再現し、
**限界が常にデータ量だった**ことも実証された（1,416サイドで約48%、6,925サイドで 55.7%、
実物が 56.4%）。**アルゴリズムではなく供給量だった。**

### 5.4 反復対戦の安定性と検出下限

**同一バイトの tar を繰り返し提出して、安定性を直接測った。**

| tar（バイト同一） | n | ドロー | 平均 | sd |
|---|---|---|---|---|
| champion | 5 | 936.7 / 980.4 / 976.0 / 945.0 / 917.8 | **951.2** | 26.6 |
| soup | 3 | 938.0 / 973.5 / 921.1 | **944.2** | 26.7 |

**中身が同一でも sd≈27。差分は sd≈38 なので単発ペアで検出できるのは約 76 Elo 以上だけで、
これまでのラダーA/Bは全てこの下限を下回っていた。**
閉じるのは個別の実験ではなく**方法論**である。判定したい効果量（+30 Elo 級）が
分解能を下回る以上、1ペアでオフライン指標を較正する手続きは成立しない。

同じ過小評価は最後にも起きた。締切24.6h前に両枠を入れ替えた結果は
**846.1 / 817.3** で、過去6ドロー（平均 944.7）から **3.7σ 下**。フィールドは平坦だった。
**n=6 で見積もった sd を信用しすぎた。**

### 5.5 オフライン評価はデッキ乗り換えを予測できない

| クローン | オフライン評価 | ラダー |
|---|---|---|
| 1回目 | 対チャンピオン **58.1%**（n=2,400, 8.0σ） | **−259.4 Elo** |
| 2回目 | 帯加重 **+5.1pp**、アーキタイプ実勝率を **0.7pp 差で再現** | **−186.1 Elo** |

**2回目は失敗作ではない。**実ラダーの勝率を 0.7pp で再現した唯一のクローンで、
どのオフライン指標でもチャンピオンを上回っていた。**それでも 186 Elo 負けた。**
1回目は2回目に 53.5% で勝つ。**より良く見えるほうが、より大きく負けた。**
1回目は出荷物と重み・md5・60枚すべての一致を再検証済みで、正常に動作する個体である。

仮説はこうである（**未検定であることを明記する**）。
アーキタイプ行列が測るのは「そのアーキタイプの**全使用者の平均**」なので、
それを自分の期待値に使うのは**自分が平均的な熟練度で操縦できる**という仮定に等しい。
このクローンは教師プール外のチームにも 66.3% 一致する＝**平均的な使い手**を学んでおり、
移植先では**試合の 58.4% が同型戦**になる。**同型戦は方策の質の差がそのまま出る場所である。**

デッキ選択の効果量は 19.1pp、対してデータ増は 2,000サイドあたり +0.6pp、忠実度改善は 0pp。
**最も効果量の大きい変数だけが、測れなかった。**

> **そうと分かった時点でやるべきことは、指標を作り直すことではなく、
> 測れないまま賭けるかどうかを決めることだった。**

### 5.6 人間の直観の扱い

チャンピオンは KO 可能な36回のうち29回（**80%**）を見送る。明白なバグに見えた。
修正する前に、対照群を置いて測った。

| 条件 | 勝率 |
|---|---|
| 無改造 | **44.7%** |
| 探索呼び出しのみ（判断は上書きしない） | 41.7%（ns） |
| **リーサル強制上書き** | **28.3%（z=−3.33）** |

**修正すると −13.4pp で有意に悪化した。探索を呼ぶこと自体は無害で、
害は判断を上書きした部分に集中していた**ので、計算コスト等の交絡は排除できる。
機構はルールにある。**攻撃がターンを終える**ため、KO を取ると相手に手番を渡す。
**KO できても見送るのが正しい局面が実在する。**

> **人間の事前分布をハードな制約として方策に注入する前に、対照群を置いて測る。**
